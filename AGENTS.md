**Tugas Rest API**
1. Kerjakan seluruh langkah C.1 sampai C.7, termasuk tiga percobaan pada bagian C.5.
2. Sebelum menjalankan setiap program, tambahkan satu baris console.log berisi nama lengkap dan stambuk Anda pada baris paling atas file, sehingga identitas tersebut tercetak di setiap output yang Anda dokumentasikan.
3. Susun laporan praktikum dengan sistematika berikut: halaman sampul yang memuat judul praktikum, nama, dan stambuk; hasil dan pembahasan untuk setiap bagian C.1 sampai C.7; jawaban pertanyaan refleksi; serta kesimpulan. Untuk setiap bagian, sertakan screenshot kode dan output terminal-nya, lalu jelaskan dengan kalimat sendiri apa yang terjadi dan mengapa output tersebut muncul.
4. Pembahasan bagian C.3 wajib menjelaskan mengapa request tanpa header User-Agent ditolak GitHub, sedangkan pembahasan bagian C.5 wajib membandingkan penyebab dan output ketiga percobaan, yaitu HTTP error 400, TypeError ketika res.ok tidak diperiksa, dan network error.
5. Pembahasan bagian C.6 wajib memuat output program cuaca-kota.js untuk empat input: Palu, Atlantis, tanpa argumen, dan satu nama kota pilihan Anda sendiri yang mengandung spasi.
6. Pembahasan bagian C.7 wajib memuat screenshot Postman untuk kedua endpoint beserta perbandingan nilainya dengan output program.
